/*
  Relay computer: solve 2 linear equations with 2 unknowns and show them on 32x32 display
  ----------------------------------------------------------------------------------------
      a*x + b*y = c
      d*x + e*y = f

  Signed input range for this 16-bit version:
      a,b,c,d,e,f = -39..+39

  Results:
      daten[900] = X10  (37 means 3.7, -13 means -1.3)
      daten[901] = Y10

  Method:
      D  = a*e - b*d
      Nx = c*e - b*f
      Ny = a*f - c*d

      X10 = sign(Nx/D) * floor((10*abs(Nx) + abs(D)/2) / abs(D))
      Y10 = sign(Ny/D) * floor((10*abs(Ny) + abs(D)/2) / abs(D))

  Multiplication and division are both implemented in software.
  MUL accepts signed operands. DIV works on the positive magnitudes prepared by the main code.

  Demo equations:
      3*x + 7*y = 2
      4*x + 6*y = 7

  Exact solution:
      x = 3.7
      y = -1.3

  Expected fixed-point results:
      X10 =  37 = 0x0025
      Y10 = -13 = 0xFFF3

  Display:
      8-row block 1: a, b -> c as 8-bit binary values
      8-row block 2: d, e -> f as 8-bit binary values
      8-row block 3: horizontal line
      8-row block 4: X10 left (16 bit), Y10 right (16 bit)

  The center rows used are y=3, 11, 19 and 27.
*/
